enmaas
Open source · Apache-2.0
v0.7.1 · Claude Code and Codex

For people whose AI coding assistant does bulk reading and sorting

Send bulk AI work to another model and keep it out of your session.

enmaas sends bulk or one-shot work to another model and writes each answer to a file. Your assistant gets back only a short receipt. A 150,000-token document can be read and summarized without any of it entering the session that asked.

The problem. A coding assistant sends the whole conversation back to the model on every step. When it reads a long document or works through a list of 300 items inside the session, every later step costs more. Much of that work is simple enough for a cheaper or free model, but the assistant has no easy way to hand it off.

You get a command line tool, a skill (a short instruction file that tells Claude Code and Codex when to delegate), an output guard that stops the assistant from reading the answers straight back, and an installer that sets up all three.

Later steps cost less

The delegated answer never joins the conversation, so the assistant does not pay to send it again on every step that follows.

Bulk jobs run side by side

enmaas map takes a list of items and sends them several at a time. Shared instructions go once per group of ten items, so you do not pay for them once per item.

A free model can be enough

On an 80-item rule-checking task with known correct answers, the free default model matched the in-session result (98.8 percent accuracy) for 95 percent less. That is one kind of task. Check it against your own work.

How a request moves through enmaas

What it is for, and what it is not for. Delegate work where each item stands alone, needs no tools, and is useful as a file: classifying, extracting, rewriting, triaging, summarizing a long file, or getting a second opinion. Debugging, test-and-fix loops, steps that depend on each other, and decisions stay with the assistant. enmaas sends a request and saves the answer. It does not iterate.

From a long document to a short receipt

The assistant needs the gist of a large file. It delegates the read, gets a receipt and a short preview, and asks you only if it needs the whole answer.

Example: one question, then a bulk job

Real commands
enmaas ask -f docs/reference.md -o /tmp/summary.md <<'PROMPT'
Summarise this reference in ten bullet points.
PROMPT

enmaas map --items items.jsonl --template template.txt --outdir out
enmaas inspect out/a.md          # first 2,000 characters
enmaas allow-read out/a.md       # you, in your terminal: allow a full read
enmaas usage --since 30          # what you have spent in 30 days

items.jsonl holds one item per line, each with an id. A ===PER ITEM=== line in the template separates the shared instructions from the part filled in for each item.

The job finished

Exit code 0. The answers are in the output folder, the receipt names the model and the tokens used, and the session never saw the answers.

Some items failed, or the run stopped

Exit code 2 means some items failed, and results.jsonl lists them. Exit code 3 means enmaas stopped the run on purpose: too many requests failed, or the token budget ran out. Run it again with --resume to skip the finished items. Exit code 1 is a setup or input error.

Choosing a model

The default model is free and accepts very long inputs (a context of one million tokens). Paid Claude, GPT, and Gemini models work through the same key. For a second opinion on work a Claude model did, pick a model from a different family, because models with shared training tend to share blind spots. Reasoning (the model's hidden thinking) counts against the output limit, so the free models run with it off by default.

Scope. enmaas handles bulk or one-shot work against a model gateway your organization provides. It does not run tools or iterate. The accuracy figure comes from one kind of task.

Install the tool, the skill, and the guard

One installer sets up all three for whichever of Claude Code and Codex it finds.

  1. Install.

    Clone the repository and run ./install.sh with your gateway address. Put your key in the key file, then run enmaas models to confirm it works. The install guide covers every step and has a troubleshooting table.

  2. Set limits, if you want them.

    ~/.config/enmaas/config.toml sets the default model, how many requests run at once, prices per model so enmaas usage can show cost, and a token budget over a number of days.

  3. Let the assistant use it.

    The skill tells Claude Code and Codex when to delegate. The assistant gets receipts and previews. If it needs a whole answer, it asks you, and you allow it with enmaas allow-read in your own terminal.

Install

git clone https://github.com/enmaas-cli/enmaas-cli.git
cd enmaas-cli
./install.sh --gateway https://GATEWAY-HOST \
  --key-file ~/.secrets/enmaas
enmaas models

config.toml

base_url = "https://GATEWAY-HOST"
concurrency = 4

[budget]
window_days = 30
tokens = 50_000_000

The repository is also a Claude Code plugin. If you install the skill and guard from a plugin marketplace, run ./install.sh --cli-only so they are not installed twice.

Exit codes: what the result means and what to do
CodeMeaningWhat to do
0Everything succeededContinue
1A setup or input errorRead the message and fix the setting or the command
2Some items failedCheck results.jsonl in the output folder
3The run stopped early: too many failures, or the token budget ran outRun again with --resume. For a budget stop, raise the limit first

A good first test

Pick one bulk task your assistant does by looping, such as classifying a few hundred items or reading one long document. Run it through map or ask on the free default model. Then compare the receipt with what the same work cost inside the session.
