For people whose assistant does bulk or one-shot model work

Delegate the bulk work. Keep it out of your context.

enmaas delegates model work to a hosted model gateway from the command line, or lets your coding assistant do it. Answers go to files. Only a short receipt comes back, so a 150,000-token document can be read and summarized with none of it landing in the session that asked.

A CLI, a skill that teaches Claude Code and Codex when to delegate and how to handle the results, an output guard that keeps delegated answers out of the assistant's context, and an installer that sets up all three.

Answers go to files

Every later step in the session is cheaper, because every tool call re-sends the whole conversation and the delegated answer is not in it.

Bulk work stops multiplying

enmaas map sends each item on its own, several at once, and batches shared instructions once per group of ten when the template allows.

Measured, then chosen

On an 80-item rule-checking task scored against ground truth, the free default model matched the in-session result for 95 percent less. The cheapest paid model scored lower and cost more. One task class; check it against your own work.

Where enmaas sits between the assistant and the gateway

What stays with the assistant. Delegation is for work that is independent per item, needs no tool calls, and is useful as a file: classifying, extracting, rewriting, triaging, summarizing a long file or diff, second opinions. Debugging, test-and-fix loops, dependent steps, and decisions stay in the session. enmaas cannot iterate.

From a long document to a short receipt

The assistant needs the gist of a large module. It delegates the read, gets a receipt and a preview, and asks you only if it needs the whole answer.

Example: one-shot and bulk

Real commands
enmaas ask -f big_module.py -o notes.md <<'PROMPT'
Summarise what this module does. Name functions. Do not cite line numbers.
PROMPT

enmaas map --items items.jsonl --template prompt.txt --outdir out --concurrency 4
enmaas inspect out/f001.md        # first 2,000 characters
enmaas allow-read out/f001.md     # let an assistant read all of it, once
enmaas usage --since 30

items.jsonl holds one JSON object per line with an id. A ===PER ITEM=== line in the template separates shared instructions from the per-item part.

Exit 0: all succeeded

Answers are in the outdir, the receipt names the model and tokens, and the session never saw the bodies.

Exit 2 or 3: partial, or stopped on purpose

Partial failure leaves results.jsonl to check. A circuit breaker trip or a spent token budget stops the run; re-run with --resume, and raise the ceiling first for a budget stop. Exit 1 is a config, auth, or validation error with the fix named.

Models and reasoning

Free models cost nothing and have no budget to spend; the default is a free model with a 1M context. Paid Claude, GPT, and Gemini models cost money. For a second opinion on work a Claude model did, pick a different family: shared lineage means shared blind spots. Reasoning tokens come out of the output budget, so the free models default to thinking off.

Scope stated. enmaas is a delegation tool for bulk or one-shot work against one organization's hosted gateway. It cannot iterate or run tools. The accuracy figure is from one task class and should be checked against your own work. The repository is private.

Install the CLI, the skill, and the guard

One installer sets up all three. Put your key in the secrets file and run enmaas models.

  1. Install.

    Clone and run ./install.sh. The install guide walks through every step, the host setup, and what to do when something fails.

  2. Configure, optionally.

    ~/.config/enmaas/config.toml sets the default model, concurrency, prices per model so usage can price calls, and a token budget over a window of days.

  3. Let the assistant use it.

    The skill tells Claude Code and Codex when to delegate. The assistant gets receipts and previews. If it needs a whole answer, it asks, and you grant it with enmaas allow-read in your own terminal.

Install

git clone https://github.com/enmaas-cli/enmaas-cli.git
cd enmaas-cli
./install.sh
enmaas models

config.toml

default_model = "<the free default>"
concurrency = 4

[budget]
window_days = 30
tokens = 50_000_000

-m MODEL is optional everywhere. Without it the configured default is used and the receipt says (default).

A focused first evaluation

Pick one bulk task your assistant does by looping: classify a few hundred items, or read one long document. Run it through map or ask on the free default and compare the receipt with what the in-session version cost.
