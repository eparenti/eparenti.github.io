Job Assistant
Version 0.2.3
563 tests · in real user testing

For someone with a repetitive job and Claude Code

Show it one example. It builds the tool.

Job Assistant turns the repeated parts of a job into tools you use by asking in plain words. You show it one real example of a task, it builds a tool for that task, checks the tool on your example, and keeps it for next time. It learns from your corrections, and every result stays a draft until you send it yourself.

It works inside Claude Code on a Mac or a Linux computer, in a terminal or in the Code section of the Claude desktop app. The install script asks at most four questions and opens the first session.

Tailored from the job description

Setup reads your job description, asks two or three questions, notes the tools you already look after, and opens your tools page with first steps at the top.

Learns from corrections

"That was wrong", "always", and "never" become learned rules, after a check that they do not spoil earlier results. "What have you learned?" shows them; "forget that" removes one.

Never acts in your other systems

Posting, sending, editing, sharing, and deleting in other systems are blocked by the folder's settings as well as by instructions. It prepares drafts and tells you where to paste them.

Where it sits in your day

What a draft is. Every result is a draft until you send it yourself. A number for leaders stays "Draft, not checked" until you approve it, and "is this number safe to send?" compares it with the last published number and checks it against the method.

From a repeated task to a tool you can call

You drop in a weekly report you build by hand. The assistant builds a tool that does the steps, runs it on that report, shows the result, and from then on "build the weekly report" runs it.

Example: what to say

Real phrases
"set up my job assistant"          setup from your job description
"automate this" + a file           a new tool, built and checked on your example
"check this brief"                 the tool runs, by the words it lists
"that was wrong" / "always ..."    a learned correction, after a regression check
"is this number safe to send?"    number sign-off against the last published number
"anything I should know?"         up to three things that need you, such as a tool that is due

"show my tools" opens your tools page. "retire" and "bring back" put a tool away or restore it.

The tool works on your example

It is kept under your tools, listed on your tools page with the words that run it, and ready for next time.

It breaks or gives a wrong answer

Say so. The assistant finds the cause and explains it plainly, and a correction becomes a learned rule only if it does not spoil earlier results.

In real user testing

Version 0.2.3 runs end to end from a fresh clone with 563 passing tests. The kit is in real user testing with one tester. Findings from that testing are open, and the interface will change.

Limits stated. It does not work in Cowork, which does not load locally installed plugins. Google Drive drafts need a claude.ai sign-in; with Vertex AI, Bedrock, or an API key, drafts stay in the folder. The README's install steps were written while the repository was private and still say so.

Install for one person

One script checks for Claude Code and git, installs uv if it is missing, signs in to GitHub if needed, installs the plugin, creates the assistant folder, and opens the first session.

  1. Run the install script.

    Someone with the kit sends you install.sh, or you fetch it with gh. It asks your first name, whether to use the desktop app, whether to add a shortcut, and whether to install uv.

  2. Trust the folder and set up.

    Answer yes to the trust prompt; the folder's settings apply only after that. Say "set up my job assistant" and share your job description.

  3. Update the same way.

    Run the script again. It updates the plugin and keeps your folder, tools, rules, and files exactly as they are.

Install

bash ~/Downloads/install.sh
# or, signed in to GitHub with gh:
gh api -H "Accept: application/vnd.github.raw" repos/job-assistant-kit/job-assistant/contents/install.sh | bash

By hand

claude plugin marketplace add job-assistant-kit/job-assistant
claude plugin install job-assistant@job-assistant
claude plugin list

Options: --folder PATH, --source PATH for a local copy of the kit, --app desktop or --app terminal, --no-start, and --yes.

A focused first evaluation

Install it for one person with one repetitive weekly task. Automate that task from one real example, run it the next week, and correct it once. Then ask "what have you learned?"
