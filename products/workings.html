For anyone who wants to understand how language models work

Turn the knobs. Watch a real model respond.

Workings is an arcade-style course on how AI language models work. Each lesson is playable: you change the inputs and watch a real, small model respond, instead of reading words and looking at pictures.

The model engine is TypeScript and runs entirely in the browser: a tokenizer, byte-pair encoding, bigram and transformer models, sampling, and a token machine that replays training curves. There is no server and no API key.

Playable lessons

A lesson is a cabinet with knobs. What you learn from is the system's real behavior under the inputs you chose.

A real model in the browser

Tokenization, byte-pair encoding, bigram and transformer models, and sampling all run client-side in TypeScript.

Lessons with a contract

Lesson definitions follow a contract and a lint checks them. A workbench exists for building and checking new lessons.

Where the pieces sit

What a lesson claims. That the behavior on screen is the real behavior of a small model running in your browser, under the inputs you chose. Not every lesson has complete content yet, and the status banner says so.

From a knob to a changed probability

A lesson lets you change an input and watch the model's next-token distribution change, then sample from it. The number you see is the number the model computed.

Run it locally

Node and npm. Clone, install, start the dev server.

  1. Install and start.

    npm ci, then npm run dev, and open the URL Vite prints.

  2. Test and build.

    npm test type-checks and runs the vitest suite. npm run build makes the production build in dist/.

  3. Add a lesson.

    Follow the contract in src/lessons, run the lint, and use the workbench to check it.

Run

git clone https://github.com/ostinato-forge/workings.git && cd workings
npm ci
npm run dev

Check

npm test
npm run build
